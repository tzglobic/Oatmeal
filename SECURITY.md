# Security reporting

Do not post API keys, recordings, meeting databases, private attendee information,
or unredacted diagnostics in public issues or pull requests.

If private vulnerability reporting is enabled for this repository, use the
Security tab's **Report a vulnerability** action. Otherwise, open an issue containing
only a request for a private contact channel, without vulnerability details or
sensitive attachments. No response-time guarantee is currently published.

When reporting privately, provide the affected commit/version, impact, reproducible
steps using synthetic data, and any proposed mitigation. If credentials were
exposed, revoke or rotate them with their provider; deleting a file or commit alone
does not invalidate a credential.

See [privacy and storage](docs/privacy.md) for the current local/cloud boundaries.
